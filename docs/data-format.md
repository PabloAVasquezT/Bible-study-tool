# Data format

The app reads static JSON files from `public/data/`. They are generated by the scripts in `scripts/data/` from pinned upstream sources and committed to the repository, so a build never depends on those sources being online. TypeScript types for everything below live in [`src/lib/bible.ts`](../src/lib/bible.ts).

## Regenerating

```sh
npm run data:bibles
```

Upstream files are downloaded once into `.cache/sources/` (ignored by git) and checked against the SHA-256 hashes in [`scripts/data/sources.ts`](../scripts/data/sources.ts). If an upstream file changes, the script stops; review the change, then update the hash.

The USFM parser is strict on purpose: an unknown marker is an error, not something to skip. Each Bible also declares its expected verse count (31,102 for the KJV), and the script fails if the total differs.

## Bibles

```
public/data/bibles/
  index.json        list of available Bibles
  kjv/
    index.json      metadata and the list of books
    GEN.json        one file per book, named by its USFM code
    ...
```

### `bibles/index.json`

```json
[{ "id": "kjv", "name": "King James Version", "abbreviation": "KJV", "language": "en" }]
```

### `bibles/<id>/index.json`

Metadata, license and source, plus one entry per book with the number of verses in each chapter, so that a passage picker can be drawn without loading any book:

```json
{
  "id": "kjv",
  "license": "Public Domain",
  "source": { "name": "eBible.org", "url": "https://ebible.org/find/details.php?id=eng-kjv2006" },
  "books": [{ "id": "GEN", "name": "Genesis", "abbreviation": "Gen", "title": "The First Book of Moses, called Genesis", "verses": [31, 25, 24] }]
}
```

### `bibles/<id>/<BOOK>.json`

A book is a list of chapters, and a chapter is a list of verses. Chapter and verse numbers are not stored: chapter *n* is at index *n − 1*, and so is verse *n*. The files have one verse per line so that changes produce readable diffs.

```json
{ "id": "GEN", "chapters": [{ "verses": [{ "break": "paragraph", "text": ["In the ", { "t": "beginning", "s": "H7225" }] }] }] }
```

**Chapter**

| Field | Description |
|---|---|
| `title` | Optional. Text before verse 1, such as a psalm superscription ("A Psalm of David…"). |
| `subscription` | Optional. Text after the last verse, such as the note at the end of Paul's epistles ("Written to the Romans from Corinthus…"). |
| `verses` | The verses, in order. |

**Verse**

| Field | Description |
|---|---|
| `break` | Optional. `paragraph` starts a new paragraph, `line` a new poetry line, `stanza` a new poetry stanza. Without it, the verse continues the current paragraph. |
| `heading` | Optional. A heading shown before the verse, such as "ב BETH." in Psalm 119. |
| `text` | The verse text, as a list of inlines. It can be empty: see below. |

All Bibles share the KJV's chapter and verse slots, so the same index points to the same slot in every Bible. Some translations number a few passages differently; the Spanish RV1909 starts Jonah 2 with the verse the KJV numbers Jonah 1:17. Our RV1909 source keeps the Spanish numbering inside the KJV slots, which leaves 18 slots empty (and, in a few places, two Spanish verses merged into one slot). An empty verse is such a placeholder: the reader skips it.

**Inline**

Each inline is one of:

- A **string**: plain text.
- A **word**, `{ "t": text, "s"?: strong, "f"?: flags }`: a run of text with Strong's numbers and/or style flags. Strong's numbers are normalized to a letter and a number without leading zeros (`H430`, `G26`), matching the lexicon keys. A word that translates several original words has several numbers separated by spaces: in the RV1909, "de Jesucristo" is `G2424 G5547`.
- A **note**, `{ "note": inlines }`: a translator's or marginal note, placed where it appears in the text.

The flags are a bit mask:

| Bit | Meaning | Usual rendering |
|---|---|---|
| 1 | Words supplied by the translators | Italics |
| 2 | The divine name (LORD, GOD) | Small capitals |
| 4 | Words of Jesus | Red letters |

Inline fields use one-letter keys because there are hundreds of thousands of them: the KJV has 349,308 Strong's-tagged words. Whitespace is always a plain string and never carries flags.

The KJV takes 14.1 MB on disk and about 2.3 MB with gzip, which is what travels over the network when the server compresses the files. The app loads one book at a time.
